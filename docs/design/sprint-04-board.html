Plain language description
Adds a season chip to the map filter bar. Tapping it filters visible locations to those marked for that season — spring, summer, fall, winter. Multiple seasons can be selected simultaneously.
Technical description
Reads season tags from the locations SQLite table. Renders chip row in the filter bar component. Applies filter to the map annotation layer — locations with non-matching season tags are hidden from the map view.
Acceptance criteria
Selecting a season chip filters the map correctly. Multiple selections show the union. Deselecting all seasons returns all locations. Chip state persists across map pans and zooms.

Plain language description
Lets the solo filter map locations by season, time of day, and location type. The solo can narrow a busy map down to exactly the locations relevant to their current planning context.
Technical description
Filter bar component added above the map view. Filter state held in local state, applied to the map annotation layer on change. Reads season, time_of_day, and type fields from the locations table. No server round-trip on filter change.
