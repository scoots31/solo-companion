Plain language description
Calculates a player's consistency score from historical game data and returns a value the score display screen can render. Handles edge cases for rookies and players with limited game history.
Technical description
Python service that queries MFL API game log endpoint, aggregates per-game scoring deltas, computes a weighted rolling average, and returns a ConsistencyScore model. Partial flag set when game_count < 6.
Acceptance criteria
Score is accurate within ±0.1 for all test fixtures. Partial flag renders correctly. API timeout handled gracefully — returns cached value, not error.
